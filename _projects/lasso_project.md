**Course Project (Optional) - CS 101 Computer Programming and Utilization**

Guide: [Prof. Bhaskaran Raman](https://www.cse.iitb.ac.in/~br/webpage/)

I developed a **C++** game involving throwing lasso ropes and catching coins using the **TurtleSim Graphics** package. 
Implemented the concepts of classes, pointers, vectors, constructors, and functions in the game and created a user-friendly graphical interface with **two** game modes and **three** difficulty levels.
